# Neurotok

## Probar (solo 3 pasos)
1. Descomprime el zip y entra a la carpeta:  cd neurotok
2. Instala todo:  bash instalar.sh
3. Arranca la app:  bash iniciar_app.sh

En Expo Go (Play Store): "Enter URL manually" -> exp://127.0.0.1:8081
Arranca en modo DEMO, no necesita nada más.

## Modo real (opcional)
1. Pon tus API keys en backend/cuentas.json
2. En otra sesión de Termux:  bash iniciar_backend.sh
3. En la app: pestaña ⚙️ -> "API real"
